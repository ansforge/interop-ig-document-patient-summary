## Exemples CDA

### Vue d'ensemble

Les exemples CDA présentent des instances concrètes de documents IPS en format CDA R2, illustrant comment structurer et valider les données cliniques conformément aux spécifications de ce guide.

### Exemple IPS-FR

**[Exemple IPS-FR 2024.01](Binary-patient-summary.md)**

Cet exemple montre un document IPS complet au format CDA R2 niveau 3 :

* Structure complète d'une synthèse médicale
* Sections cliniques principales remplies
* Métadonnées d'en-tête correspondant au contexte français
* Données codifiées selon les terminologies recommandées

### Utilisation des exemples

Ces exemples peuvent être utilisés pour :

* Valider la conformité de vos implémentations CDA
* Servir de base pour générer vos propres documents IPS
* Tester l'intégration avec vos systèmes d'information
* Référencer les bonnes pratiques de structuration
