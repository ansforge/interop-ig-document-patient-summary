## Exemples IHE XDM

### Vue d'ensemble

Les exemples IHE XDM (Cross-Enterprise Document Media Interchange) présentent comment les documents IPS en format CDA peuvent être packagés et échangés sur des médias physiques (clé USB, DVD, etc.) conformément au standard IHE XDM.

IHE XDM définit un format standardisé pour :

* Organiser les documents cliniques sur un média physique
* Garantir l'intégrité et l'authenticité des documents
* Faciliter le transport sécurisé des documents entre professionnels de santé
* Assurer la compatibilité entre différents systèmes d'information

### Structure des exemples

Les exemples présentent :

* **Les documents IPS en CDA** au sein d'une structure XDM
* **L'organisation des fichiers** selon les spécifications IHE
* **Les métadonnées d'échange** nécessaires pour l'interopérabilité
* **Les cas d'usage pratiques** de transmission de documents

### Utilisation des exemples

Ces exemples peuvent être utilisés pour :

* Valider la conformité de vos implémentations XDM
* Comprendre la structure correcte des packages XDM
* Tester l'intégration entre votre système et d'autres systèmes supportant XDM
* Servir de base pour créer vos propres documents XDM

### Exemple concret

Un exemple complet d'implémentation XDM pour l'IPS en France est disponible sur le dépôt ANS :

* **[Exemple IHE XDM - IPS-FR_2024.01](https://github.com/ansforge/interop-exemples-xdm/tree/main/IPS-FR_2024.01)** - Exemple de package XDM contenant un document IPS en CDA, avec la structure et les métadonnées conformes au standard IHE XDM

Cet exemple peut être téléchargé et utilisé pour valider vos implémentations ou comme point de départ pour créer vos propres packages XDM.
